# 🌐 Shagun Gupta — Portfolio Website

A responsive personal portfolio website showcasing my skills, education, 
and projects, built as the final project for the Web Development Internship.

---

## 📌 About

This portfolio highlights my journey as a B.Tech CSE student and aspiring 
full-stack developer, featuring my projects, technical skills, and ways to 
connect with me.

## ✨ Features

- Responsive design (desktop, tablet & mobile)
- Dark / Light mode toggle
- Filterable project showcase (All / AI / Frontend / Full Stack)
- Contact form with input & email validation
- Semantic HTML structure with Flexbox & Grid layouts
