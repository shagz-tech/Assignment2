## ✅ What's Covered

### Week 2 — CSS Fundamentals
- **CSS Selectors** — Element, Class, ID, Universal selectors with colors, backgrounds, fonts & text alignment
- **Box Model** — Width/height, margin, padding, border, border-radius, box-shadow
- **Flexbox** — Flex container, direction, justify-content, align-items, gap, horizontal & vertical alignment
- **CSS Grid** — Grid container, rows/columns, gap, item placement, gallery layout
- **Responsive Design** — Media queries for mobile, tablet & desktop screens
- **Mini Project** — Combines all above concepts into one cohesive, responsive page

### Week 3 — JavaScript Fundamentals (Part 1)
- **JS Basics** — syntax, `console.log()`, comments, linking JS with HTML
- **Variables & Data Types** — `let`, `const`, String, Number, Boolean, `undefined`, `null`, `typeof`
- **Operators** — arithmetic, assignment, comparison, logical, increment/decrement
- **Conditional Statements** — `if`, `if...else`, `else if`, nested `if`
- **Loops** — `for`, `while`, `do...while`
- **Practice Programs** — palindrome check, simple calculator, and more, combining all Week 3 concepts

### Week 4 — JavaScript Fundamentals (Part 2)
- **Functions** — declarations, parameters, arguments, return values, arrow functions
- **Arrays** — creating, accessing, adding, removing, updating, iterating, array methods
- **Objects** — creating objects, properties, accessing/updating/adding/removing properties
- **DOM Manipulation** — selecting elements, changing text/HTML content, changing CSS styles, adding/removing elements
- **Events** — click, input, change, submit, mouse/keyboard events
- **Mini Project** — Interactive To-Do List combining Functions, Arrays, Objects, DOM & Events
