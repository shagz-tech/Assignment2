# 🎨 CSS Fundamentals — Week 2 Assignment

> Internship Program | Web Development Track

A collection of HTML5 + CSS3 pages demonstrating core styling concepts — 
selectors, box model, flexbox, grid, and responsive design — built as part 
of the Week 2 internship assignment.

---

## 🎯 Objective

To understand the fundamentals of CSS by learning how to style HTML 
webpages, use different selectors, manage spacing and layouts using the 
Box Model, create layouts using Flexbox and Grid, and make webpages 
responsive using Media Queries.

## ✅ What's Covered

- **CSS Selectors** — Element, Class, ID, Universal selectors with colors, backgrounds, fonts & text alignment
- **Box Model** — Width/height, margin, padding, border, border-radius, box-shadow
- **Flexbox** — Flex container, direction, justify-content, align-items, gap, horizontal & vertical alignment
- **CSS Grid** — Grid container, rows/columns, gap, item placement, gallery layout
- **Responsive Design** — Media queries for mobile, tablet & desktop screens
- **Mini Project** — Combines all above concepts into one cohesive, responsive page
